# KO侧载超频

此公开站点仅提供 KO 模块下载、注册与捐赠网页、收款码、公开机型清单和当前 API 入口。云端 API、数据库、白名单/黑名单原件、SMTP 配置、管理员凭据、手机通知附加模块及配对密钥由私有服务器和私有源码仓库维护，不在本公开仓库中分发。

## 用户入口

- 首页：`index.html`
- 设备登记：`register.html`
- 捐赠页面：`donate.html`
- 微信/支付宝收款码：`sponsor-qr.png`、`sponsor-alipay.jpg`
- 当前 HTTPS API 入口：`cloud.txt`
- KO侧载超频 1.0.12：`KO侧载超频_1.0.12.zip`
- 包 SHA-256：`KO侧载超频_1.0.12.zip.sha256`

模块自动识别设备型号、SoC、内核和显示驱动，并验证主板 ID 授权、Ed25519 签名及 KO 文件 SHA-256。模块在刷入界面显示识别机型；不匹配或未授权时不会加载 KO。

捐赠页面会展示本仓库中的二维码。付款确认及一次性注册链接邮件由 KO 独立 API 处理。二维码文件与当前管理员配置的收款码保持一致。

管理页 `admin.html` 供管理员使用。注册审核、授权名单、黑名单、签名文件、捐赠队列、SMTP、手机通知日志和收款识别都由独立 KO API 提供。管理员从服务器本机访问时直接进入；远程 API 管理仍需要服务端凭据。

手机通知附加模块只放在私有交付中。它同时上报 AaTempSpoof 主服务与 KO 独立服务，两个目标使用各自的公网入口和签名密钥；公开仓库不提供该模块或任何配对密钥。

公开仓库不包含服务端源码、运行目录、数据库、原始名单、SMTP 凭据、签名私钥、管理员 Token、通知 APK/native listener、手机通知模块或配对密钥。
